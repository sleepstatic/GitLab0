1. git clone- скачать проект из интернета на компьютер
2. git status- проверить какие файлы изменились в папке
3. git add- выбрать файлы и подготовить их к сохранению
4. git commit- сохранить выбранные файлы в историю проекта
5. git push- отправить свои сохранения в интернет на Github
6. git init- создать репозиторий в папке
7. git pull- скачать чужие новые сохранения с Github
8. git log- посмотреть историю всех прошлых сохранений
9. git branch- сделать копию проекта, чтобы кодить отдельно  
10. git checkout- переключиться на другую ветку проекта
